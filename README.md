# Visit2.ge

სასტუმროს სისტემა საქართველოს მცირე სასტუმროებისა და ბინების მეპატრონეებისთვის: საიტი, ჩატბოტი და ადმინი, ასევე კატალოგი, სადაც სტუმარი პირდაპირ ჯავშნის. მეპატრონე თვეში ფიქსირებულ თანხას იხდის და არა საკომისიოს თითო ჯავშანზე.

პროტოტიპი: [Villa JIJI](https://villajiji.com), ბაკურიანი (რეპოზიტორია `villajijiweb/Villajijiwebsite`).

## დოკუმენტები

- [docs/BRIEF.md](docs/BRIEF.md): პროექტის აღწერა: იდეა, ფასები, ფულის მოდელი, იურიდიული საკითხები, ბრენდი, ეტაპები.
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): multi-tenant არქიტექტურა და სამუშაო გეგმა.
- [brand/](brand/): ლოგოები (Visit2 და ᲕᲘᲖᲘᲢ2), ხატულები და ფერები.

## სტეკი

Cloudflare Workers (სტატიკური ფაილებით), D1, R2. გამოწერები Stripe-ით.

## სტატუსი

- ✅ **ეტაპი 0:** Worker, ბაზის სტრუქტურა `tenant_id`-ით, სასტუმროს პოვნა დომენით, ტესტები ორი სასტუმროთი.
- ⏭ **ეტაპი 1:** ფასები და თავისუფალი ნომრები ვილა ჯიჯის `core.js`-იდან.

პროექტი ჯერ მხოლოდ GitHub-ზეა. Cloudflare-ზე არაფერი არ არის გაშვებული.

## ლოკალურად გაშვება

```sh
npm install
npm test        # SQL-ის შემოწმება (tenant_id) და ტესტები
npm run dev     # http://test-one.localhost:8787 და http://test-two.localhost:8787
```

## სტრუქტურა

```
src/index.js       სასტუმროს პოვნა დომენით და მარშრუტი
src/db/            ყველა SQL აქ არის; თითო ფუნქცია სასტუმროს (t) პირველ არგუმენტად იღებს
src/lib/           დრო (საქართველო, UTC+4), სეზონები, HTML
migrations/        ბაზის სტრუქტურა (wrangler d1 migrations)
scripts/check-sql.mjs  ამოწმებს, რომ ყველა მოთხოვნას სასტუმროს ცხრილზე tenant_id აქვს
test/              ტესტები Workers-ის გარემოში (Miniflare)
```
