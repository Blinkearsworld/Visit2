# Visit2.ge

სასტუმროს სისტემა საქართველოს მცირე სასტუმროებისა და ბინების მეპატრონეებისთვის: საიტი, ჩატბოტი და ადმინი, ასევე კატალოგი, სადაც სტუმარი პირდაპირ ჯავშნის. მეპატრონე თვეში ფიქსირებულ თანხას იხდის და არა საკომისიოს თითო ჯავშანზე.

პროტოტიპი: [Villa JIJI](https://villajiji.com), ბაკურიანი (რეპოზიტორია `villajijiweb/Villajijiwebsite`).

## დოკუმენტები

- [docs/BRIEF.md](docs/BRIEF.md): პროექტის აღწერა: იდეა, ფასები, ფულის მოდელი, იურიდიული საკითხები, ბრენდი, ეტაპები.
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): multi-tenant არქიტექტურა და სამუშაო გეგმა.
- [brand/](brand/): ლოგოები (Visit2 და ᲕᲘᲖᲘᲢ2), ხატულები და ფერები.

## სტეკი

Cloudflare Workers (სტატიკური ფაილებით), D1, R2. გამოწერები Stripe-ით.

## სტატუსი

- ✅ **ეტაპი 0:** Worker, ბაზის სტრუქტურა `tenant_id`-ით, სასტუმროს პოვნა დომენით, ტესტები ორი სასტუმროთი.
- ✅ **ეტაპი 1:** ფასები, თავისუფალი ნომრები, „ფანჯრები“ და აქციები ვილა ჯიჯის `core.js`-იდან, სასტუმროს სეზონებით.
- ✅ **პირველი ვერსია (ეტაპები 2–4, ნაწილობრივ):** ადმინი ელფოსტით შესვლით (ჯავშნები, კალენდარი, ფასები, გადახდები, გუნდი, ჟურნალი, საიტის მართვა), სასტუმროს საიტი ზოგადი შაბლონით, ჯავშნის ფორმა და ჩატბოტი. ყველაფერი ვილა ჯიჯის კოდიდანაა, სასტუმროების მიხედვით გაყოფილი.
- ✅ **პლატფორმა (დემო):** Visit2.ge-ს მთავარი გვერდი სტუმრებისთვის (ძებნა ქალაქით, თარიღით, სტუმრებით) და გვერდი მფლობელებისთვის (შაბლონები, ფასები, საიტის შექმნა). სასტუმროს საიტს სამი შაბლონი აქვს: ქვა, ეზო, ქალაქი. დემო: https://blinkearsworld.github.io/Visit2/
- ⏭ **შემდეგი:** ადმინის ახალი ვიზუალი და ახალი „საიტის მართვა“; კატალოგის API სერვერზე.
- ⏭ **შემდეგ:** გაშვება Cloudflare-ზე ([docs/DEPLOY.md](docs/DEPLOY.md)), შემდეგ საიტის სერვერზე შევსება (SEO) და თარგმანები.

პროექტი ჯერ მხოლოდ GitHub-ზეა. Cloudflare-ზე არაფერი არ არის გაშვებული.

## ლოკალურად გაშვება

```sh
npm install
npm test        # SQL-ის შემოწმება (tenant_id) და ტესტები
npm run dev     # http://test-one.localhost:8787 და http://test-two.localhost:8787
                # ადმინი: /admin, one@example.com / test-one-123 (მხოლოდ ლოკალურად)

node scripts/new-hotel.mjs …   # ახალი სასტუმროს SQL (იხ. ფაილის თავი)
```

## სტრუქტურა

```
src/index.js       სასტუმროს პოვნა დომენით (ან /h/{slug}/ წინასწარ ნახვაზე) და მარშრუტი
src/api.js         სასტუმროს API: საჯარო (state, request, content) და ადმინის
public/index.html  Visit2.ge: სასტუმროების ძებნა (სტუმრებისთვის)
public/owners.html მფლობელებისთვის: შაბლონები, ფასები, რეგისტრაცია
public/hotel.html  სასტუმროს საიტი; site/site.js + site/themes/*.css (შაბლონები)
public/admin.html  სასტუმროს ადმინი (ჯერ ვილა ჯიჯის ვიზუალით)
src/db/            ყველა SQL აქ არის; თითო ფუნქცია სასტუმროს (t) პირველ არგუმენტად იღებს
src/lib/           დრო (საქართველო, UTC+4), სეზონები, HTML
migrations/        ბაზის სტრუქტურა (wrangler d1 migrations)
scripts/check-sql.mjs  ამოწმებს, რომ ყველა მოთხოვნას სასტუმროს ცხრილზე tenant_id აქვს
test/              ტესტები Workers-ის გარემოში (Miniflare)
```
